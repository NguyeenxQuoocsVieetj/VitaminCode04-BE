Cách hoạt động

  1. Cảm biến đo

    ESP32 đọc nhiệt độ, độ ẩm và thẻ NFC.

  2. Truyền dữ liệu

    Gửi JSON lên server qua WiFi (MQTT/HTTP).

  3. Xử lý & lưu trữ

    Server kiểm tra ngưỡng và lưu vào cơ sở dữ liệu.

  4. Hiển thị & cảnh báo

    Dashboard cập nhật realtime, cảnh báo khi vượt ngưỡng.
